## 5. Coach 引导与学生回答

### 开课诊断记录（2026-08-26）

| 题目 | 学生回答 | Coach 反馈 |
| --- | --- | --- |
| Flexbox 水平、垂直居中 | `justify-content: center`、`align-items: center` | 正确。默认 `flex-direction: row` 时，前者控制水平主轴，后者控制垂直交叉轴；主轴方向改变后不能机械地把二者等同于水平和垂直。 |
| `100%` 与 `100vw` | 相对父组件；相对视窗 | 基本正确。更严谨地说，`100%` 通常依据包含块的可用宽度，不一定是 Vue 意义上的“父组件”；`100vw` 是视口宽度。 |
| `<style scoped>` | 样式只作用在组件内，避免污染全局 | 正确。它通过编译后附加属性来限制选择器范围，但不是完全隔离的 Shadow DOM。 |
| 有输入框为何仍需 CSS | 登录页还有其他组件，需要 CSS 排版 | 正确。进一步说，Element Plus 负责控件，CSS 负责页面结构、间距、品牌视觉和响应式布局。 |

诊断结论：学生已掌握本节所需的基础 CSS 概念。后续减少基础语法讲解，重点考察组件库与业务样式的职责边界，以及响应式页面的实际实现。

#### 学生追问与 Coach 解释（2026-08-26）

学生追问：结构图中的 `login-page`、`login-shell`、`brand-panel` 是否是 HTML 标签。

Coach 解释：它们是描述页面区域的 CSS 类名，不是浏览器内置标签。实现时需要选择 `main`、`section`、`div` 等真实 HTML 标签，并通过 `class` 赋予区域名称。例如 `<main class="login-page">`。结构图为了突出组件层级，省略了具体标签的尖括号。

### 引导二：理解组件库的边界

组件库提供的是可靠的“积木”，不是完整的“房子”。输入框、按钮有统一状态和交互，但背景、卡片位置、品牌区域和响应式布局属于具体产品设计，仍由页面样式负责。
